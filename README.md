# Irene 的遊戲小站 🎮

這裡收藏我自己設計的網頁小遊戲，用手機或電腦的瀏覽器打開就能玩，不用安裝。

## 遊戲清單

| 遊戲 | 簡介 | 開始玩 |
|---|---|---|
| 🐻‍❄️ **北極熊炸彈運動會** | 選一隻北極熊，放炸彈打敗三隻電腦熊！一關比一關難，每關都有不同的陷阱。 | [▶ 點這裡玩](https://momo21502002.github.io/game/polar-bear-bomb/) |

## 怎麼玩
- **電腦**：方向鍵或 WASD 移動，空白鍵放炸彈。
- **手機**：建議橫著拿，左半邊滑動控制方向，右半邊點一下放炸彈。
